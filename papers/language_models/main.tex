\begin{abstract}
This paper investigates adversarial vulnerabilities in natural language processing (NLP), large language models (LLMs), and automatic speech recognition (ASR) using BiLSTM-GloVe for sentiment analysis, Qwen-1.5 for advanced reasoning, and Wav2Vec 2.0 for speech-to-text tasks. We evaluate a range of attack methods, including TextFooler, jailbreak prompts, and psychoacoustic audio perturbations, alongside defenses like adversarial training, text purification, and signal processing techniques such as spectral gating. Experimental results highlight trade-offs between robustness, clean-data performance, and computational overhead, showing hybrid defenses reduce attack success rates by up to 40\%. Our unified benchmarks and defense strategies enhance the security of language AI systems for safety-critical applications like healthcare and autonomous systems.
\end{abstract}

\begin{IEEEkeywords}
Adversarial Attacks, NLP, Large Language Models, ASR, Model Robustness, Defense Mechanisms, AI Security
\end{IEEEkeywords}

\section{Introduction}
Language models, powered by deep learning, enable advanced applications in text analysis, generative AI, and speech recognition. However, their growing complexity introduces vulnerabilities to adversarial attacks, compromising reliability in real-world settings. This study examines three domains:
\begin{itemize}
    \item \textbf{NLP}: Models like BiLSTM-GloVe for tasks such as sentiment analysis and text classification, critical in social media and customer feedback systems.
    \item \textbf{LLMs}: Pre-trained models like Qwen-1.5, used for reasoning and generation, but susceptible to prompt-based attacks.
    \item \textbf{ASR}: Systems like Wav2Vec 2.0, converting speech to text, essential for virtual assistants and transcription services.
\end{itemize}
Small, crafted perturbations—textual or auditory—can cause misclassifications or harmful outputs, posing security risks. This work analyzes attack strategies and proposes robust defenses to ensure trustworthy AI deployments.

\section{Related Work}
Adversarial attacks threaten language models across NLP, LLMs, and ASR, extending vulnerabilities first identified in computer vision~\cite{goodfellow2015explaining, jin2019textfooler}.

\subsection{Adversarial Attacks}
NLP attacks manipulate text at word or character levels. TextFooler~\cite{jin2019textfooler} substitutes words with synonyms, while TextBugger~\cite{li2018textbugger} introduces character-level perturbations, both causing misclassifications while preserving readability. LLMs face jailbreak attacks, bypassing safety mechanisms with crafted prompts, and prompt injection attacks exploiting external data~\cite{zou2023universaltransferableadversarialattacks}. In ASR, imperceptible audio noise, generated via methods like FGSM or psychoacoustic techniques, triggers incorrect transcriptions~\cite{qin2019imperceptible, esmaeilpour2021towards}.

\subsection{Defense Mechanisms}
Defenses include:
\begin{itemize}
    \item \textbf{Adversarial Training}: Virtual Adversarial Training (VAT) smooths model outputs for robustness~\cite{miyato2017virtual}.
    \item \textbf{Input Purification}: Heuristics detect and correct adversarial text manipulations~\cite{morris2020textattack}.
    \item \textbf{Signal Processing}: Techniques like spectral gating and MP3 compression remove adversarial audio noise~\cite{andronic2020mp3}.
    \item \textbf{Hybrid Pipelines}: Multi-stage systems combine detection and filtering for enhanced security~\cite{zou2023universaltransferableadversarialattacks}.
\end{itemize}
While hybrid defenses improve resilience, adaptive attacks remain a challenge, necessitating ongoing research~\cite{akhtar2018threatadversarialattacksdeep}.

\section{Natural Language Processing}

\subsection{Experimental Setup}
\subsubsection{Model}
We employ a BiLSTM architecture with pre-trained GloVe 6B.100d embeddings, featuring 32 hidden units, L2 regularization (0.001), and global average pooling for binary sentiment classification.

\subsubsection{Dataset}
Yelp Polarity Reviews dataset with 560,000 training samples and 38,000 test samples, balanced across positive and negative sentiment classes.

\subsubsection{Metrics}
Attack Success Rate (ASR), Accuracy Under Attack (AuA), and ASR Reduction percentage measuring defense effectiveness.

\subsection{Attacks}
\subsubsection{Tested Attacks}
We evaluate three black-box adversarial attacks using the TextAttack framework~\cite{morris2020textattack}: TextFooler (synonym-based word substitution)~\cite{jin2019textfooler}, TextBugger (character and word-level transformations)~\cite{li2018textbugger}, and DeepWordBug (character-level perturbations)~\cite{gao2018deepwordbug}.

\subsection{Defenses}
We adopt a layered strategy that first purifies input text and then relies on a model trained with Virtual Adversarial Training (VAT).

\subsubsection{Virtual Adversarial Training (VAT)}
VAT adds embedding-space regularization during training by injecting small worst-case perturbations ($\epsilon\!=\!2.0$, $\xi\!=\!10^{-6}$) into the word-embedding layer, smoothing decision boundaries and improving baseline robustness~\cite{miyato2017virtual}.

\subsubsection{Character-Level Purification}
Before inference, each sentence passes through a lightweight purifier that (i) normalizes excessive letter repetitions, (ii) repairs single-edit errors (deletions, insertions, substitutions) via edit-distance search, and (iii) corrects adjacent character swaps. Corrections are accepted only when the result matches the vocabulary.

\subsubsection{Proposed Adaptive Defense Pipeline}
The adaptive defense pipeline combines lightweight detection with robust mitigation:
\begin{enumerate}
    \item \textbf{Detection Stage:} 8-bit quantization applied to input audio
    \item \textbf{Decision Logic:} Classifies as adversarial if transcription dissimilarity (WER) larger than 12\%
    \item \textbf{Mitigation Stage:} For detected attacks, applies Spectral Gating (SG) + MP3 compression (64kbps)
\end{enumerate}

\section{Large Language Models}
\subsection{Attacks}
We implemented two white-box Jailbreak attacks that induce aligned language models to produce virtually any objectionable content. Experiments were conducted on the aligned Qwen-1.5-1.8B model and using the AdvBench dataset. Attack performance was assessed via attack success rate (ASR), where outputs without refusal were considered successful, in addition to manual review and metrics including Precision, Recall, and F1 Score to reduce false negatives and false positives.\\
\subsubsection{Greedy Coordinate Gradient Attack}
The GCG \cite{zou2023universaltransferableadversarialattacks} is a greedy and gradient based white-box jailbreak attack. It appends an adversarial suffix to the query that attempts to confuse the model to respond. 

The key objective is to minimize the adversarial loss function, defined as the negative log-likelihood of a target affirmative response sequence (e.g., ``Sure, here is...'').
We implemented two distinct approaches for adversarial suffix optimization:
 \begin{enumerate}
    \item Optimizing an adversarial suffix for each individual harmful prompt.
    \item  Optimizing a single universal suffix for a set of prompts using a weighted loss function that prioritizes prompts with higher difficulty.
\end{enumerate}
Gradients are computed to identify \( k = 256 \) candidate token substitutions, evaluating \( B = 128 \) random substitutions using greedy search to yield the lowest loss. This process repeats for \( T = 50 \) iterations, targeting a 20-token suffix.

\subsubsection{Beam search-based Adversarial Attack}
The BEAST attack \cite{zou2023universaltransferableadversarialattacks} also appends an adversarial suffix to individual user prompts. Unlike
the Greedy Coordinate Gradient (GCG) attack, BEAST utilizes a computationally efficient, gradient-free beam
search optimization scheme. This approach processes one prompt at a time,
optimizing the adversarial suffix with tunable hyperparameters to balance attack speed, success rate, and prompt readability.

The key objective is to minimize the perplexity of the target harmful string. It iteratively expands a beam of \( k_1 = 15 \) candidates, sampling \( k_2 = 15\) tokens per candidate, and selecting the top \( k_1 \) candidates with the lowest perplexity for a 30-token suffix.
