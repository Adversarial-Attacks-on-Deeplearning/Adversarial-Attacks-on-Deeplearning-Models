\begin{abstract}
This paper investigates adversarial attacks and defenses in deep learning for computer vision, focusing on EfficientNet-B1 (image classification), U-Net (image segmentation), and YOLOv8n (object detection) across benchmarks like GTSRB, Carvana, and Self Driving Cars. We analyze white-box and black-box attack methods and evaluate defenses including adversarial training, JPEG compression, noise fusion, and dynamic preprocessing pipelines. Our results highlight trade-offs between robustness, accuracy, and computational cost, offering benchmarks and guidelines for securing AI systems in safety-critical applications.
\end{abstract}

\begin{IEEEkeywords}
Adversarial Attacks, Deep Learning, Image Classification, Semantic Segmentation, Object Detection, Model Robustness, Defense Mechanisms, AI Security
\end{IEEEkeywords}

\section{Introduction}
Computer vision, powered by deep learning, enables breakthroughs in object recognition, scene understanding, and autonomous navigation. This study examines adversarial vulnerabilities in three tasks:
\begin{itemize}
    \item \textbf{Image Classification}: Assigning labels using models like EfficientNet-B1, critical for medical diagnostics and autonomous vehicles.
    \item \textbf{Image Segmentation}: Pixel-level partitioning with U-Net, vital for biomedical imaging and self-driving cars.
    \item \textbf{Object Detection}: Localizing objects with YOLOv8n, essential for real-time perception in safety-critical systems.
\end{itemize}
Despite advances, these models remain vulnerable to adversarial attacks, where imperceptible input perturbations cause misclassifications or detection failures, posing risks in real-world settings.

\section{Related Work}
Adversarial attacks exploit vulnerabilities in computer vision models, particularly in safety-critical applications like autonomous vehicles and medical diagnostics~\cite{szegedy2014intriguingpropertiesneuralnetworks, goodfellow2015explaining}.

\subsection{Adversarial Attacks}
Early work demonstrated image classification vulnerabilities, with methods like Fast Gradient Sign Method (FGSM)~\cite{goodfellow2015explaining}, Projected Gradient Descent (PGD)~\cite{madry2018towardspgd}, and Carlini \& Wagner (C\&W)~\cite{carlini2017evaluatingrobustnessneuralnetworks} generating subtle yet effective perturbations. Attacks on object detection and segmentation, including Universal Adversarial Perturbations (UAPs)~\cite{moosavi2017universal} and physical-world adversarial patches~\cite{3d_physical_attacks}, disrupt localization and pixel-level predictions.

\subsection{Defense Mechanisms}
Defenses include:
\begin{itemize}
    \item \textbf{Adversarial Training}: Uses adversarial examples to enhance robustness~\cite{madry2018towardspgd}.
    \item \textbf{Input Transformations}: JPEG compression and noise fusion mitigate perturbations~\cite{das2017keepingbadguysout}.
    \item \textbf{Certified Defenses}: Randomized smoothing offers robustness guarantees~\cite{cohen2019certified}.
    \item \textbf{Hybrid Pipelines}: Combine detection and purification for efficient security.
\end{itemize}
No defense is universally effective, especially against adaptive attacks, driving ongoing research~\cite{akhtar2018threatadversarialattacksdeep}.

\subsection*{White-Box Attacks}
In the \textbf{white-box} setting, where the attacker has full knowledge of the model's architecture and parameters, our evaluation included:

\begin{itemize}
    \item \textbf{Gradient-Based Methods:} We began with foundational attacks like the \textbf{Fast Gradient Sign Method (FGSM)}, a single-step method that creates perturbations by moving in the direction of the loss function's gradient. We then employed its powerful iterative extension, \textbf{Projected Gradient Descent (PGD)}, which applies multiple smaller steps to find more optimal perturbations. To test against more advanced techniques, we used the \textbf{Momentum Iterative FGSM (MI-FGSM)}, which integrates a momentum term to stabilize update directions and create more transferable adversarial examples~\cite{goodfellow2015explaining,madry2018towardspgd,dong2018boosting}.

    \item \textbf{Minimal Perturbation Attacks:} We utilized \textbf{DeepFool}, an iterative attack that geometrically projects an input to the nearest decision boundary, aiming to find the minimum possible perturbation required to cause a misclassification~\cite{moosavidezfooli2016deepfoolsimpleaccuratemethod}.

    \item \textbf{Targeted and Saliency-Based Attacks:} The \textbf{Jacobian-based Saliency Map Attack (JSMA)} was used to evaluate targeted threats. This method uses the model's Jacobian matrix to identify and modify the most influential input pixels to steer the model's prediction toward a specific incorrect class~\cite{papernot2016limitations}.

    \item \textbf{Universal, Image-Agnostic Attacks:} We also generated a \textbf{Universal Adversarial Perturbation (UAP)}, a single, fixed noise pattern designed to fool the model on a wide variety of inputs, demonstrating systemic vulnerabilities rather than input-specific ones~\cite{moosavidezfooli2017universaladversarialperturbations}.
\end{itemize}

\subsection*{Black-Box Attacks}
For the more realistic \textbf{black-box} scenario, where the attacker has limited to no knowledge of the model's internals, we evaluated:

\begin{itemize}
    \item \textbf{Decision-Based Attacks:} These attacks only require the model's final predicted label. We tested the \textbf{HopSkipJumpAttack}, a highly query-efficient method that estimates the gradient direction at the decision boundary to find minimal perturbations with few model queries~\cite{chen2020hopskipjumpattackqueryefficientdecisionbasedattack}.

    \item \textbf{Score-Based and Minimalist Attacks:} We employed the \textbf{One-Pixel Attack}, an extreme method using an evolutionary algorithm to find a successful adversarial example by changing just a single pixel~\cite{Su_2019}. Additionally, we used the \textbf{Simple Black-box Attack (SimBA)}, which iteratively probes the model by adding or subtracting small values along random directions (in either pixel or frequency space) to reduce the confidence score of the correct class~\cite{guo2019simple}.
\end{itemize}

\subsection{Defenses}
\subsubsection{Tested Defeses}
\paragraph{Adversarial Training}
 Adversarial examples are generated dynamically during each training step using the current model, ensuring evolving and challenging perturbations. Training starts with mostly clean data and gradually increases adversarial exposure, using FGSM early and PGD later with adaptive strength. This approach builds robust decision boundaries and prevents memorization of specific attack patterns\cite{zheng2020efficientadversarialtrainingtransferable}.
\paragraph{Noise Fusion}
Noise matrix sampled from Uniform, Gaussian, or Poisson distributions is blended with the input image using a weighted sum controlled by amplitude $\alpha$. During training, noise is added to enhance robustness via data augmentation. During inference, noise suppresses adversarial perturbations. The same fusion formula $\mathbf{x}_{\text{noise}} = (1 - \alpha) \cdot \mathbf{x} + \alpha \cdot \mathbf{n}$ is applied in both phases.

\cite{shi2022noisefusion}
\paragraph{JPEG Compression}
JPEG compression serves as a simple yet effective preprocessing defense by targeting high-frequency adversarial noise. Gradient-based attacks like FGSM and PGD often rely on fine-tuned high-frequency perturbations, which are disrupted during JPEG's quantization step. This model-agnostic approach can help restore correct classifications by smoothing out adversarial effects.
\cite{das2017keepingbadguysout}

\subsection{Defenses}
We applied adversarial training to a U‑Net segmentation model by jointly training on clean images and FGSM‐generated adversarial examples at \(\epsilon=8/255\), \(16/255\), and \(32/255\). Each batch contains both clean inputs and perturbed versions created by adding the sign of the loss gradient scaled by \(\epsilon\) and clamping to \([0,1]\). The overall loss is a weighted sum  
\[
0.5\,L_{\text{clean}} + 0.2\,L_{\text{adv}_{8/255}} + 0.2\,L_{\text{adv}_{16/255}} + 0.1\,L_{\text{adv}_{32/255}},
\]  
balancing clean‐image accuracy with robustness. All losses are computed using binary cross‐entropy.

\subsection{Defenses}
\subsubsection{Tested Defeses}
\paragraph{Adversarial Training}
Adversarial training Incorporates adversarial examples during training~\cite{madry2018towardspgd}. we added to the Self Driving Cars dataset (10,590 clean images) 8,252 adversarial examples, creating a mixed corpus of 18,842 images. The adversarial subset includes 2,000 PGD, 3,000 FGSM, 500 Targeted DAG, 1,500 UAP, and 1,500 FoolDetectors examples~\cite{goodfellow2015explaining,madry2018towardspgd,xie2017DAG,moosavi2017universal,lu2017fooldetectors}. This diversity prevents overfitting to specific attacks.





\paragraph{Dynamic Preprocessing Pipeline}
A two-stage pipeline detects and purifies adversarial inputs, minimizing overhead for clean images. Stage 1 uses a MobileNetV2 classifier to flag adversarial images (threshold: 0.3), trained on 14,000 images (7,000 clean, 7,000 adversarial: 2,000 PGD, 2,000 FGSM, 1,500 UAP, 500 Targeted DAG, 1,000 FoolDetectors)~\cite{goodfellow2015explaining,madry2018towardspgd,moosavi2017universal,xie2017DAG,lu2017fooldetectors}. It achieves 99.8\% accuracy on the test set and 92.5\% on unseen attacks. Stage 2 applies JPEG compression (quality: 30), Gaussian blur ($\sigma=1.5$), and random resizing (scale: 0.8–1.2) to flagged images, with bounding box rescaling to maintain label integrity.
