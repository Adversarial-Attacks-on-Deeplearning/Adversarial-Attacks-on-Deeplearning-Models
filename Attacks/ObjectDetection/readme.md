# DAG Attack 

## Overview
The Dense Adversarial Generation (DAG) attack is an iterative gradient-based attack designed to generate adversarial examples that mislead object detection models. DAG attacks can be used in two ways:
1. **Targeted DAG Attack**: Modifies an image to make the detector misclassify objects into adversarial classes while removing target objects.
2. **Disappearance DAG Attack**: Aims to make certain objects disappear from detection by lowering their confidence scores.

## Implemented Attacks
### 1. Targeted DAG Attack
This attack perturbs the input image such that specific target objects disappear while forcing the model to detect adversarial classes instead.

#### Parameters:
- `model`: The object detection model.
- `images`: Input images to be attacked.
- `target_objects`: Classes of objects to remove.
- `adversarial_classes`: Classes to be introduced.
- `max_iter` (default=20): Maximum iterations for gradient updates.
- `gamma` (default=0.1): Step size for adversarial perturbation.
- `output_dir` (default="targeted_dag_attack_adversarial_images"): Directory to save adversarial images.
- `im_name_prefix` (default=""): Prefix for saved image names.
- `CUDA` (default=True): Flag for GPU usage.

#### Attack Steps:
1. Load and preprocess images.
2. Iteratively compute gradients to maximize adversarial class confidence and minimize target class confidence.
3. Apply perturbations to the image and clamp pixel values between `[0,1]`.
4. Stop early if all adversarial classes appear while target objects disappear.
5. Save the generated adversarial images.

---
### 2. Disappearance DAG Attack
This attack perturbs the input image to remove specified target objects from detection.

#### Parameters:
- `model`: The object detection model.
- `images`: Input images to be attacked.
- `target_objects`: Classes of objects to remove.
- `max_iter` (default=20): Maximum iterations for gradient updates.
- `gamma` (default=0.1): Step size for adversarial perturbation.
- `output_dir` (default="disappearance_adversarial_images"): Directory to save adversarial images.
- `im_name_prefix` (default=""): Prefix for saved image names.
- `CUDA` (default=True): Flag for GPU usage.

#### Attack Steps:
1. Load and preprocess images.
2. Iteratively compute gradients to decrease detection confidence of target objects.
3. Apply perturbations to the image and clamp pixel values between `[0,1]`.
4. Stop early if all target objects disappear.
5. Save the generated adversarial images.

---
## Saving Adversarial Images
The adversarial images generated by both attacks are saved in their respective directories with names formatted as:
```
<im_name_prefix>_adv_<index>.png  # For targeted attack
<im_name_prefix>_<index>_adv_disappear.png  # For disappearance attack
```

## Usage Example
```python
adversarial_images, perturbations = targeted_dag_attack(
    model=my_model,
    images="path/to/image.jpg",
    target_objects=[0, 1],  # Classes to remove
    adversarial_classes=[2, 3],  # Classes to introduce
    max_iter=20,
    gamma=0.1,
    CUDA=True
)
```

---
## Notes
- The attacks assume that the model outputs detections in the YOLO format.
- Early stopping is implemented for efficiency when the attack succeeds before `max_iter`.
- Ensure the `write_results` and `prepare_image` functions work correctly with your model.

## Introduction <a name="introduction"></a>

This project demonstrates Universal Adversarial Perturbation (UAP) attacks on a U-Net model trained for medical image segmentation. The attack generates a single perturbation pattern that degrades model performance across multiple input samples while remaining barely perceptible to human observers.

## What are UAP Attacks? <a name="what-are-uap-attacks"></a>

Universal Adversarial Perturbations are input-agnostic patterns that:
- Can fool neural networks when added to any input
- Work across multiple samples (universal)
- Require no knowledge of specific input data
- Maintain visual similarity to original inputs
